# Third-party components

StrokeScape packages independently maintained components. Their copyrights and
licenses remain with their respective owners. License texts are included in the
portable archive's `ThirdParty/` directory and the bundled Chromium directories.

- CPython — Python Software Foundation License; <https://www.python.org/>.
- NumPy — BSD; <https://numpy.org/>.
- OpenCV — Apache-2.0; <https://opencv.org/>.
- Pillow — HPND; <https://python-pillow.org/>.
- FastAPI, Starlette, Uvicorn, Pydantic, pywebview — see included license texts.
- React, Vite, TypeScript and Lucide — see upstream licenses; front-end assets
  retain the license comments generated by the build tools.
- Playwright — Apache-2.0; <https://github.com/microsoft/playwright>.
- Chromium — Chromium BSD and other included third-party licenses. The complete
  browser distribution includes its license/credits files. <https://www.chromium.org/>.
- FFmpeg — the bundled BtbN **LGPL shared** build is unmodified and is run as a
  separate executable. Its LGPLv3 license, exact build version, configure options
  and publisher checksum are included under `ThirdParty/FFmpeg/`.
  FFmpeg: <https://ffmpeg.org/>. Build scripts: <https://github.com/BtbN/FFmpeg-Builds>.
  Matching FFmpeg source and the build-recipe snapshot are provided as separate
  assets alongside the portable ZIP in the same GitHub release.

The current CPU portable edition does not bundle CuPy or the CUDA toolkit.

No license has yet been selected for the StrokeScape project's own source code;
publication of this repository does not change third-party license terms.
