# 笔刷与画布检查

## 使用

- 在“笔刷风格”中选择圆笔、石墨铅笔、马克笔、干刷、水彩、油画、点彩或彩色铅笔，点击生成；切换风格不会静默替换现有作品。
- 画布支持滚轮缩放、放大后拖动、双击复位；手机可用双指缩放或缩放按钮。
- “适应”将图片完整显示；“1:1”使用原始像素，缩放百分比以原始像素为基准。
- 点击“对比”，拖动分界线查看原图和当前绘画进度。分界线可用左右方向键、Home、End 调整。
- 预览的缩放、位移和对比线只影响检查视图，不改变 HTML / MP4 的像素尺寸和画面。

## 实现边界

`backend/brushes.py` 和 `public/renderer.js` 采用相同的种子、线束偏移、宽度、透明度与断续段规则；测试跨 Python / JavaScript 核对几何与种子结果。OpenCV 反馈画布与 Canvas 在亚像素、线帽和抗锯齿上仍有差别，不能声称像素一致。

笔刷参数存放在 `settings.brush`；旧作品缺省为 `classic`。精度预设与笔刷是独立选项，切换精度不覆盖笔刷选择。纹理按笔触编号生成，回退播放与视频导出不重新随机取样。

八种笔刷属于确定性的程序化风格模拟。石墨铅笔会转为灰阶，其余笔刷保留色彩。水彩采用多层不同宽度与透明度的叠色；油画采用高覆盖底笔和明暗线束；点彩每条笔触由一组圆点组成，按路径进度逐点出现；彩色铅笔采用五束细线交叠。此实现不包含颜料扩散、纸张纤维或真实压力传感仿真。

## 验证

- 全部后端测试包含八种笔刷生成、参数验证、默认旧设置、跨语言几何和圆点一致性、逐点播放稳定性和 HTML 数据保留。
- 浏览器实际操作检查了旧版 150,000 笔作品、滚轮缩放、拖动、1:1 像素大小、滑块端点和手机分界线拖动。
- 手机宽度检查未出现横向溢出，测试后恢复默认窗口尺寸。
- 从界面选择干刷后实际生成 777 笔，保存的风格为 `dry`，数量匹配。
- 干刷 6,000 笔作品通过正式流程导出 HTML 与 H.264 MP4，视频约 15 秒。
- 八种笔刷分别在同一张“乙木”展示图上生成 12,000 笔作品并导出 HTML；新增点彩通过正式流程导出约 15 秒 H.264 视频。
- 彩色铅笔通过界面实际生成 1,201 笔；手机端八种笔刷以四列两行显示，检查未发现横向溢出。
