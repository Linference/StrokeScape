# 创作工具与验证

## 局部精修

打开已完成作品，切到左侧“局部精修”，点击“框选精修区域”。画布显示最终绘画，可直接拖动框选；也可输入 X、Y、宽、高，坐标以作品像素为准。关闭框选后可继续缩放和拖动检查画面。

输入追加笔触（每次 200–100,000 笔，累计上限 500,000），点击开始。系统复制原图及原作笔触快照，创建新作品。只有新笔触携带选区裁剪信息；原有路径、颜色、笔形、种子和纹理保持不变。最终画面选区外不受新增笔触影响。

追加部分使用当前笔刷参数。整体仍按设定总时长播放，因此原有笔触的时间分配会重新编排。精修前须重放已有笔触以建立反馈画布，大作品仍有初始化成本；它并非只读取选区的小型计算。

## 笔刷与生成策略

“创作设置 → 笔刷与生成策略”可调：

- 粗细 0.3–3 倍，着色强度 0.2–1.5 倍。
- 纹理 0–2 倍，控制线束偏移和点彩散布；圆笔保持平滑笔形。
- 断续留白 0–2 倍，作用于石墨铅笔、彩铅和干刷。
- 自然绘画顺序：在候选笔触中兼顾残差、距离和颜色变化，每 48 笔重新进行全局候选采样，减少长期局部停留。此为可解释启发式，不保证每幅图的观看体验都更好。
- 自适应停止：可选，默认关闭以保留精确笔数模式。只在细节层以 512 笔为窗口检查选区或整图 MAE。连续三个窗口的改善低于阈值，或误差足够低时，提前结束；铺底、塑形、勾线仍执行。

参数在重新生成或精修时生效，不会静默改写当前作品。每条笔触可携带自己的笔刷、种子、纹理、留白及裁剪，因此多次精修、换风格、导入后仍能确定性重播。预览、HTML 和 MP4 使用同一份 Canvas 渲染器。

## 过程预览与质量面板

后台大约每秒发布一张最长边不超过 640 的反馈画布缩略图；进度单独显示在画布下方，可切换原图检查。短任务可能直接显示最终结果。

“绘制图层 → 作品概览”显示 MAE、PSNR、平均落笔间距和细节误差曲线。反馈画布由 OpenCV 绘制，与 Canvas 的线帽、透明度与抗锯齿有差异，指标和过程缩略图均为近似值。指标不代表美术风格好坏或动画自然度。

## 作品管理与工程

作品集卡片支持编辑名称与标签，最多 12 个标签、每个最多 24 字。搜索匹配名称和标签，标签按钮可单独筛选。删除、恢复与彻底删除见[回收站说明](deleting-works.md)。

导出面板和作品卡片提供 `.strokescape` 工程下载；作品集提供“导入工程”。工程是包含 `manifest.json`、`input.png` 和 `work.json` 的 ZIP，不需要联网。导入产生独立作品，保留原图、笔触形态、时间轴、设置、名称与标签，视频需要另行导出。

导入限制压缩包与解压数据为 160 MB，并校验版本、尺寸、笔触数量、有限数值、串行时间轴、递进图层及裁剪范围；仅读取固定的三个文件，不解压任意路径。

## 同图不同预算实验

运行：

```powershell
.venv/Scripts/python.exe -m scripts.compare_budgets docs/media/sample-source.png --edge 512
```

本次同一张用户授权“乙木”展示图、288 × 512、CPU、圆笔、种子 42、自然顺序开启、自适应停止关闭，单次本机测量：

| 笔触 | 生成秒数 | 近似 MAE ↓ | 近似 PSNR / dB ↑ |
| ---: | ---: | ---: | ---: |
| 20,000 | 2.21 | 17.7691 | 19.6413 |
| 60,000 | 10.28 | 15.1561 | 20.7680 |
| 150,000 | 22.64 | 14.2633 | 20.8929 |
| 500,000 | 63.93 | 13.4744 | 21.0028 |

该例误差随预算下降，但改善逐渐减小。时间包括缩略图回调开销，受后台负载影响，未重复测量，不能作为其他图片、尺寸或设备的保证。CSV 和参数记录保存在 `artifacts/budget-comparison/`。

- 精修单元测试逐像素核对选区外不变，同时验证原数据不被修改。
- Python / JavaScript 核对八种笔刷在非默认纹理、留白与种子下的几何；Canvas 裁剪上下文也有独立验证。
- 自适应停止在均匀纸色测试图上实际减少笔触；自然顺序在固定测试图上减少平均跳跃距离。
- 测试历史库迁移、回收站、元数据、工程往返、越界路径、非有限数值、重叠时间轴与精修预算上限。
- 隔离库实际生成 60,000 笔干刷作品，界面提交选区追加 1,200 笔；原作保留，新作成功导出工程、HTML 和 H.264 MP4。
- 实际工程经本地接口重新导入，回收站恢复通过界面验证；自动浏览器文件上传受扩展权限限制，未更改用户扩展设置。
