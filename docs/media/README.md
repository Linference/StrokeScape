# 展示素材

这些素材用于仓库 README，来自本项目代码生成的原创示例“山间来信”（`backend/demo.py`），没有使用用户照片或第三方画作。

| 文件 | 内容与来源 |
| --- | --- |
| `studio.png` | 当前源码版工作台的实际截图。作品为 12,345 笔、960 × 730、90 秒；展示自定义数量输入和时间轴。 |
| `sample-source.png` | 内置原创示例原图，1000 × 760。 |
| `sample-painted.png` | 下方 MP4 的末段解码帧，960 × 730，展示实际压缩视频效果。 |
| `drawing-demo.mp4` | 软件实时画布录制导出的 H.264 视频；18,000 笔、960 × 730、约 14.96 秒，CPU 笔触生成，随机种子 42。 |
| `drawing-demo.gif` | 从 MP4 转为宽 600 像素、12 FPS、96 色的循环预览；为便于仓库首页展示降低了分辨率和色彩数量。 |

截图与演示视频为独立任务，笔数和播放时长不同。视频时长不代表笔触生成耗时，也不代表所有图像或设备的性能。素材中没有录入桌面、声音或私人作品。

仅文档展示使用这些文件，软件运行不依赖此目录。
