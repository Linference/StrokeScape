# 展示素材

这些素材用于仓库 README。展示图片“乙木·春生万物”由用户提供，并指定用于本仓库的演示；不将其标注为本项目原创或另行授予素材许可。软件内置原创示例仍为“山间来信”（`backend/demo.py`）。

| 文件 | 内容与来源 |
| --- | --- |
| `studio.png` | 当前源码版工作台的实际截图。作品为 150,000 笔、941 × 1672、30 秒；展示精细预设、自定义数量输入和时间轴。 |
| `sample-source.png` | 用户指定的展示原图，941 × 1672。 |
| `sample-painted.png` | 下方 MP4 的末段解码帧，裁去编码所需的右侧单列填充，保留实际 941 × 1672 画布，展示压缩视频效果。 |
| `drawing-demo.mp4` | 软件实时画布录制导出的 H.264 视频；150,000 笔、941 × 1672 画布（编码补齐为 942 × 1672）、约 30 秒，CPU 笔触生成，随机种子 42。 |
| `drawing-demo.gif` | 从 MP4 转为高 680 像素、12 FPS、128 色的循环预览；为便于仓库首页展示降低了分辨率和色彩数量。 |

截图与演示视频为同一任务。视频时长不代表笔触生成耗时，也不代表所有图像或设备的性能。素材中没有录入桌面或声音。

仅文档展示使用这些文件，软件运行不依赖此目录。
