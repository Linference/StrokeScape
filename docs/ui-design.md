# StrokeScape 工作台改版

本轮采用明亮中性背景、白色面板和紫色强调色，并提供独立的深色外观。
界面样式统一为 `src/studio.css` 中的语义颜色变量，不再加载两套旧主题叠加覆盖。

## 布局与交互

- 固定导航、紧凑标题区、设置与图层页签、大画布和播放时间轴。
- 设置面板内部滚动，生成按钮固定在面板底部。
- 自定义笔触数量直接显示在精度预设下方，提供目标笔数、恢复预设及输入范围提示；实际生成验证了 12,345 笔。
- 可收起侧栏进入专注模式。
- 作品集提供名称搜索、卡片状态和时间信息。
- 深浅外观、动效偏好保存在本机；遵循系统减少动态效果偏好。
- 导出弹窗保留实时录制和逐帧导出，并展示各自时间特征。
- 手机宽度下使用底部导航，画布优先显示，设置面板排列在其下。
