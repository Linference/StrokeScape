# 作品删除与回收站

作品卡片右上角和工作台顶部提供删除入口。确认“移入回收站”后，作品从主作品集隐藏，文件仍保存在本机。打开作品集的“回收站”即可恢复；没有自动清理期限。

回收站卡片提供“恢复作品”和“彻底删除”。彻底删除会再次显示作品缩略图、名称和提示，确认后永久清理应用内的原图副本、笔触、HTML、MP4、临时文件及数据库记录，无法撤销。应用外的原始图片和自行另存的文件不在清理范围内。

生成、排队、取消中或视频导出中的作品暂不可移入回收站。先取消并等待后台收尾。文件被其他程序占用导致彻底删除失败时，可关闭相关文件后重试。

接口：

- `DELETE /api/tasks/{id}`：移入回收站。
- `GET /api/tasks?trash=true`：查看回收站。
- `POST /api/tasks/{id}/restore`：恢复作品。
- `DELETE /api/tasks/{id}/permanent`：只允许彻底删除回收站内的作品。

历史数据库启动时追加标签与回收站字段，原有作品默认保留在主作品集。递归清理前检查解析后的绝对目录路径，拒绝指向数据目录外或其他作品的路径。

测试覆盖恢复、永久清理、历史库迁移、活动任务拦截、任务收尾、缺失目录、文件占用和目录边界。实际浏览器验证使用隔离测试库，未删除用户的真实作品。
